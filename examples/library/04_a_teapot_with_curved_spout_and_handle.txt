A teapot with a curved spout and handle. Parts: a rounded pot body, a flat circular base, a shallow domed lid, a small knob, a curved pouring spout, and a C-shaped handle.

**Key idea 1 — clean circles with no pole/seam/bulge:**
Closing a round body with polar pie-slices makes a degenerate centre point, visible seams, and a lens-shaped (non-circular) cap. Instead I use a square-to-disc mapping for the base and lid (a single grid per cap, no collapsed centre), and I build the body's rings from the SAME disc boundary loop, so each cap's rim equals the body's end ring exactly -> watertight, and the base/lid read as true circles.

**Key idea 2 — spout and handle as swept tubes that actually attach:**
Both are tubes: a small circular cross-section carried along a centre curve, each cross-section lying in the plane perpendicular to the curve's tangent (tangent t, plus d1 = the y-axis and d2 = t x d1 span that plane). The spout's centre curve starts just inside the body's +x wall, rises fairly high, and turns its tip slightly DOWN so it pours like a real spout, while its tube radius tapers from base to tip. The handle's centre curve is a C-arc on the -x side whose TWO endpoints are pinned onto the body surface (x = -body_radius at those heights) so it connects to the pot instead of floating; its tube radius is constant.

**Coordinate system:**
- Z is up (base low, knob on top); X/Y are the radial plane; everything is centred on the z-axis.

**Construction:**
- Body: a tube swept up a (z, radius) profile that bulges to its widest near mid-height then draws in to the rim. Each ring is the unit disc boundary loop scaled by that ring's radius, closed (first column == last column).
- Base: a square-to-disc grid at z=0 scaled to the bottom radius; its boundary equals the body's bottom ring.
- Lid: a square-to-disc grid domed upward, scaled to the rim radius; its boundary equals the body's top ring (it rests on the rim).
- Knob: a small square-to-disc dome on the lid centre.
- Spout: a swept tube rising from the body's +x side, fairly high up, with the tip bending DOWN only slightly for pouring.
- Handle: a swept tube on the -x side whose two ends sit ON the body surface (x = -body_radius at those heights), so it connects.
- Smooth man-made surfaces, no fine texture, so f=1 throughout.

import numpy as np
# square -> disc cap and its boundary loop (the shared ring discretization)
n = 7
u = np.linspace(-1, 1, n)
def sq(a, b): return a*np.sqrt(1-b*b/2), b*np.sqrt(1-a*a/2)
grid = [[sq(u[i], u[j]) for j in range(n)] for i in range(n)]      # (x,y) on unit disc
loop = ([grid[0][j] for j in range(n)] + [grid[i][n-1] for i in range(1, n)] +
        [grid[n-1][j] for j in range(n-2, -1, -1)] + [grid[i][0] for i in range(n-2, 0, -1)])
print("disc boundary loop:", len(loop), "pts (open); body rings reuse this, closed")

# body profile (z, radius): bulge near mid-height, narrow to the rim
prof = [(0.000,0.180),(0.080,0.350),(0.200,0.440),(0.320,0.460),
        (0.440,0.430),(0.540,0.350),(0.630,0.220),(0.700,0.200)]
zr = np.array(prof)
def body_r(z): return float(np.interp(z, zr[:,0], zr[:,1]))
# body ring = disc loop scaled by radius, at height z, closed; base/lid reuse the same loop
def ring(r, z):
    pts = [(x*r, y*r, z) for (x, y) in loop]
    return pts + [pts[0]]
body = [ring(r, z) for z, r in prof]                 # nu=8 rows, nv=len(loop)+1 cols
# square->disc cap with a height function (flat base, domed lid, domed knob)
def cap(scale, z_of):
    return [[ (grid[i][j][0]*scale, grid[i][j][1]*scale,
               z_of(grid[i][j][0]*scale, grid[i][j][1]*scale)) for j in range(n)] for i in range(n)]
base = cap(0.180, lambda x, y: 0.000)                                  # boundary == body[0]
RIM, LIDH = 0.200, 0.10
lid  = cap(RIM, lambda x, y: 0.700 + LIDH*(1-(x*x+y*y)/(RIM*RIM)))     # boundary == body[-1]
KR, KH = 0.060, 0.075
knob = cap(KR, lambda x, y: 0.800 + KH*(1-(x*x+y*y)/(KR*KR)))
print("body/base/lid/knob built; caps share the body's end rings")

import numpy as np
# swept tube: uniform circular cross-section carried along a centre path, closed around
m = 12
ca = np.linspace(0, 2*np.pi, m+1)
def tube(path, radii):
    P = np.array(path, float); out = []
    for k in range(len(P)):
        t = (P[1]-P[0]) if k == 0 else (P[-1]-P[-2]) if k == len(P)-1 else (P[k+1]-P[k-1])
        t = t/np.linalg.norm(t)
        d1 = np.array([0.0, 1.0, 0.0])           # perpendicular to the xz path
        d2 = np.cross(t, d1); d2 /= np.linalg.norm(d2)
        out.append([tuple(P[k] + radii[k]*(np.cos(a)*d2 + np.sin(a)*d1)) for a in ca])
    return out
# spout: rises high on the +x side, tip bends down only slightly, shorter reach
spout_path = [(0.34,0,0.42),(0.46,0,0.51),(0.56,0,0.60),(0.65,0,0.66),
              (0.72,0,0.69),(0.78,0,0.685),(0.83,0,0.66)]
spout = tube(spout_path, np.linspace(0.080, 0.030, len(spout_path)))
# handle: C-loop on -x; the two ends sit on the body surface so it connects
handle_path = [(-body_r(0.30),0,0.30),(-0.64,0,0.36),(-0.73,0,0.46),
               (-0.71,0,0.55),(-0.52,0,0.60),(-body_r(0.60),0,0.60)]
handle = tube(handle_path, np.full(len(handle_path), 0.040))
print("spout (bent tip) and handle (ends on body) built")
