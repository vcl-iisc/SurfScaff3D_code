A dome — the upper half of a unit sphere, sitting over the XY plane with its pole on +Z. To avoid a degenerate pole (where a whole patch row collapses to one point) and the radial bulge that a 4-quadrant surface-of-revolution gets at its rim seams, I build it as a quad-sphere (cube-sphere): one curved top cap plus four side patches, each a clean grid, all sharing edges.

**Coordinate system:**
- Z is up; the pole is at (0,0,1) and the rim sits on the z=0 circle of radius 1
- X/Y are the ground plane

**Construction:**
- Take the top face and the upper halves of the four side faces of a cube centered at the origin, then project every point onto the unit sphere (normalize to length 1). Cube edges map to smooth spherical curves, so there is no collapsed pole.
- cap: the cube top face z=1, (x,y) in [-1,1]^2 on a 7x7 grid, each point normalized -> the rounded top of the dome
- four sides (xpos/xneg/ypos/yneg): each cube side face, upper half z in [0,1], on a 5x7 grid (rim->top by 5, across by 7), each point normalized -> the flanks down to the rim
- The cap's four edges exactly equal the four side tops, adjacent sides share their vertical edges, and all four side bottoms lie on the z=0 unit circle, so the five patches join into one closed dome with a clean circular rim.
- Smooth man-made surface, so s=1.0; no fine texture, so f=1

import numpy as np
def nrm(v):
    v = np.array(v, float); return v / np.linalg.norm(v)
NC, NV = 7, 5
lin  = np.linspace(-1, 1, NC)   # across a cube face
zlin = np.linspace(0, 1, NV)    # rim -> top on a side face
# cap: cube top face z=1, projected to the sphere (7x7)
cap = [nrm((x, y, 1.0)) for x in lin for y in lin]
# one side: cube face fixed_axis=+/-1, upper half, projected (5x7)
def side(axis, sign):
    return [ (nrm((sign, t, z)) if axis == "x" else nrm((t, sign, z)))
             for z in zlin for t in lin ]
sides = {"xpos": side("x", 1), "xneg": side("x", -1),
         "ypos": side("y", 1), "yneg": side("y", -1)}
print(f"cap {NC}x{NC}; each side {NV}x{NC}; rim is the z=0 unit circle")
